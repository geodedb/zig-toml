### Task A3: Soften the "Stateless Design" claim

**Files:**
- Modify: `docs/ARCHITECTURE.md:102-103`

- [ ] **Step 1: Rewrite the sub-section**

The current sub-section (under `### 2. Lexer (lexer.zig)`) is:

```text
**Stateless Design:**
The lexer is stateless between tokens. It does not maintain context about table headers or value positions - this is handled by the parser.
```

Replace with:

```text
**Minimal-State Streaming Design:**

The `Lexer` struct carries three pieces of state across calls to
`next()`:

- `pos: Position` -- streaming byte index + line + column cursor.
- `version: TomlVersion` -- locked at init; gates v1.1-only tokens
  (e.g. time without seconds).
- `parse_error: ?ParseError` -- populated on the first lexical error
  so the parser can surface it without re-scanning.

It does not maintain higher-level context such as table headers or
value positions -- those live on the parser. The intent is "as little
state as possible," not "no state at all."
```

/// Extract the leading name after `pub const` / `pub fn`. Returns the
/// identifier up to the first space, `=`, `(`, or `:`.
fn extractPubName(line: []const u8) ?[]const u8 {
    const prefixes = [_][]const u8{ "pub const ", "pub fn " };
    for (prefixes) |p| {
        if (std.mem.startsWith(u8, line, p)) {
            const rest = line[p.len..];
            var end: usize = 0;
            while (end < rest.len) : (end += 1) {
                const c = rest[end];
                if (c == ' ' or c == '=' or c == '(' or c == ':') break;
            }
            if (end == 0) return null;
            return rest[0..end];
        }
    }
    return null;
}
